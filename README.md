# Владимир Новиков — портфолио

Статический сайт: главная, каталог и три кейса. Сборка не требуется.

## Публикация в GitHub Pages

В Settings → Pages выбрать Deploy from a branch, ветку main и папку /(root).

## Редактирование

Тексты находятся в HTML-файлах, общие стили — в style.css, изображения и шрифты — в assets/for-gpt/.
