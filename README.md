# Владимир Новиков — портфолио

Статический сайт: главная, каталог и четыре кейса. Сборка не требуется.

## Публикация в GitHub Pages

В Settings → Pages выбрать Deploy from a branch, ветку main и папку /(root).

## Редактирование

Тексты находятся в HTML-файлах, общие стили — в style.css, изображения и шрифты — в assets/for-gpt/.

## Скорость загрузки

Растровые изображения подключены в WebP через `srcset` и `sizes`: браузер выбирает размер под экран и плотность пикселей. Новые обложки имеют варианты 480, 960, 1440 и 1920 px; экраны продуктов — до исходного разрешения. Для простых схем используется сжатие без потерь, когда оно даёт меньший файл. Иллюстрации ниже первого экрана загружаются по мере прокрутки.

Шрифты переведены в WOFF2 и предзагружаются. `vercel.json` задаёт длительный кеш только для новых файлов с хешем содержимого в имени. При замене изображения или шрифта нужно менять хеш в имени и ссылки на файл: это позволяет сразу показать обновление без сброса кеша посетителями. Исходные PNG и TTF сохранены как резервные материалы и страницами больше не используются.
